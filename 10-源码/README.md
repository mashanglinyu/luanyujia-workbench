## 为什么不是"可运行项目"

诚实说三件事：

| 原因 | 具体 |
|---|---|
| **内部 API 依赖** | 面板代码依赖壳注入的 `app.*` 实例（文件系统、IPC、窗口控制）；`sessions.mjs` 依赖你本机的引擎 HTTP 接口 |
| **单机假设** | 路径、端口（3080）、exe 名、GCM 凭据都是这台机器的形状 |
| **没有测试与 CI** | 所有"自检"都是本机脚本（入口哨兵 / 索引体检 / 冷启动检查），别人 clone 下来跑不起来 |

所以它的定位是：**一份"别人真的这么写过"的参考实现** ——
你可以照着改，但别指望 `npm install && npm start` 就能跑。

> 如果你要的是"能跑的最小壳"：把 [`../01-场景模式/`](../01-场景模式/) + [`../02-会话定位与跟随/`](../02-会话定位与跟随/) 按
> [`../04-工作台搭建/从零到能跑.md`](../04-工作台搭建/从零到能跑.md) 拼起来，比读这 7,600 行更快见效。
