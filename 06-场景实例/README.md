# 06 · 场景实例 —— 10 个真跑着的场景配置

> 📁 **本目录**：10 个真跑着的场景配置：面板坐标、会话绑定、固定组（已脱敏）

> **这一节不是示例，是实例。** 下面 10 份 `json` 就是从一台**每天在用的**工作台上脱敏下来的场景配置：
> 面板类型、网格坐标、`pinTarget` 怎么钉会话、`home`/`drives`/`first` 这些细节字段，都是踩过坑之后定下来的形状。

> 名字、会话 id、路径已全部换成占位符（`<DSH根>` / `session-0000…`）；**换掉它们才能真正用**（见文末清单）。

## 为什么"行情分析"是空的

宿主点名要求：**这个场景的面板要空**。

原因值得记下来：这类场景的数据面板（看板 / 雷达 / 选股）一旦带内容，就等于把**某个人的持仓偏好、关注标的**公开了 ——
配置里哪怕只有面板标题，也能反推出他在看什么。所以这份文件只保留**骨架**：

```json
{ "id": "stock-analysis", "name": "行情分析", "layout": "grid", "cols": 8, "theme": "dark", "panels": [] }
```

你可以拿它当**空场景模板**：`layout` + `cols` + `theme` 三行就能定义一个能切过去的空场景，再往上加你自己的面板。

## 三件从这些配置里能直接学到的事

### 1. 一个场景可以有两块 AI 面板 —— 但**绝不能重名**

`dsh-gui.json` 里两块 `harness`：

| 面板 | `title` | `sessionTitle` | 负责哪半边 |
|---|---|---|---|
| `p3` | `AI·DSH改造` | `DSH改造` | 引擎/底层（`<DSH根>\引擎`） |
| `p4` | `AI·GUI页面改造` | `GUI页面改造` | 界面/外观（`<DSH根>\外壳`） |

⚠️ 两条会话**重名就会串台** —— 这是 [`../02-会话定位与跟随/四-防串台.md`](../02-会话定位与跟随/四-防串台.md) 里最贵的一条教训。
本仓库的脱敏脚本第一版就把两块都改成了同一个名字，属于**制造**这个 bug，已修。

### 2. `homeFolders` / `drives` 让面板一打开就在有用的地方

`dsh-gui.json` 的 `view` 面板带 `homeFolders`（外壳 / 引擎 / 工作区 / 场景记忆 / 工具 / 盘根），
`file` 面板带 `drives: ["C","D","E","F"]` —— 用户不用每次从盘根翻到目录。

### 3. `fixed` / `first` 是两种"不许动"

- 面板级 `"fixed": true`：这个**面板**不许被拖动/关闭；
- 场景级 `"first": true`：这个**场景标签**永远排在最前（`blender.json` 用了它）。
  两者都由 07 的固定组规则保证 —— 拖拽时只能在自己那一组内换位。

## 拷走之后必须改的 5 处（漏一处就是"看起来好了、其实没生效"）

| # | 改什么 | 不改会怎样 |
|---|---|---|
| 1 | 文件名 = `id`（`<id>.json`） | 标签栏里根本不出现这个场景 |
| 2 | `name` / `description` | 出现一个叫 `<DSH根>` / `<个人站场景>` 的怪场景 |
| 3 | 每个面板的 `id`（现在是 `p1`/`p2`…） | 与别的场景抢同一个存储键（面板内容互相串） |
| 4 | `harness` 的 `sessionId` / `sessionTitle` / `pinTarget` | 面板不钉会话：显示别人那条，或让你每次自己选 |
| 5 | `homeFolders[].path` / 任何 `<...>` 占位 | 面板打开在不存在的位置（**通常不报错，只是空白**） |

> 建议拷完先全局搜一次 `<`，再把它丢进 `scenarios/` 切一次场景看效果。
> 面板 `type` 若在你的壳里没注册，会显示一行灰字"未知面板类型"，**也不报错** —— 这是最常见的"我以为配好了"。

## 这 10 个场景是怎么分工的（不是随手切的）

看完配置你可能会问"为什么要分成 10 个"。规则只有一条：**一个场景 = 一类会反复回来的活**。

| 判据 | 举例 |
|---|---|
| 有**自己的资产目录**（改了要写回同一份记忆） | 站点 / 客户系统 / 三维工程 |
| 有**自己的专业流程**（不是通用问答能解决的） | 视频流水线 / 打包发版 |
| 会**长期反复**回来（不是一次性） | 清理 / 体检 / 复盘 |
| 反过来：**一次性的活** | ❌ 别开场景，记进当次的项目笔记就好 |

更完整的协作层（职能表 / 地盘 / 重叠判据 / 派单与回执）见 [`../05-协作与规矩/三-跨场景协作.md`](../05-协作与规矩/三-跨场景协作.md)。
