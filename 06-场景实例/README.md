# 06 · 场景实例（脱敏样板 3 份）

> 📁 **本目录**：只留 3 份能直接对得上公开版工作台的场景配置；其余场景（设计 / 开发 / 视频 / 行情 / OA 等）不公开——它们要么属成品版，要么会把客户业务形态露出来。

## 文件

| 文件 | 场景 | 面板类型 | 说明 |
|---|---|---|---|
| `bilibili.json` | B站 | `embed` + `harness` | 左边嵌网页、右边 AI；看视频时总结用 |
| `pc-cleanup.json` | 本地电脑 | `pc-drives` / `pc-toplarge` / `pc-junk` / `pc-ledger` + `harness` | 磁盘容量、大户排行、可清理体检、清理台账四块 + AI |
| `self-review.json` | 自我复盘 | `review-doc` / `review-files` / `embed` + `harness` | 左边读文档、右边浏览文件，右下 AI |

## 怎么用

1. 复制对应 json 到 `外壳\scenarios\<名字>.json`
2. 改 `id` / `name`（面板 id 建议与场景 id 一致）
3. 跑 `node 外壳\scripts\建会话.mjs --title "<场景名>"`，把输出的 `sessionId` 写回面板
4. 顶栏 ⟳ 刷新

> 想加自己的场景、面板怎么摆 → 看 [`01-场景模式`](../01-场景模式/)；字段含义见 [`01-场景模式/场景配置格式.md`](../01-场景模式/场景配置格式.md)。

## 为什么不给全部

- **暴露业务形态**：场景名、面板组合、钉的会话标题，连起来就能猜出这家客户在干什么
- **脱敏易残留**：即使把路径换成占位，字段名和枚举值仍然会漏

⚠️ 所以：这里给的是「结构样板」，不是「我们全部家底」。
