# 模板 · 可拷贝的纯壳

> 这里的文件**拷贝改名后可以使用**，不含任何个人内容。
>
> ⚠️ **但"改名就能用"只对结构成立**：模板里的**路径、会话名、会话 id、面板类型、脚本名全是占位符**，
> 必须换成你自己环境里真实存在的东西，否则表现是"看起来配好了、其实没生效"（而且不报错）。
> 动手前先读 [新手必读](../新手必读.md)。

## 拷贝后必改清单（漏一条就是"没生效"）

| # | 改什么 | 在哪 | 不改会怎样 |
|---|---|---|---|
| 1 | **文件名 = `id`** | 场景 json 另存为 `<id>.json` | 标签栏里根本不出现这个场景（解析不到） |
| 2 | **`name` / `description`** | 场景 json 顶层 | 出现一个叫 `<场景名>` 的奇怪场景 |
| 3 | **面板 `id` 前缀** | 每个 panel | 与其它场景/面板抢同一个存储键（串台） |
| 4 | **面板 `type`** | 每个 panel | 显示一行灰字"未知面板类型"，**不报错** |
| 5 | **`col` / `row` / `w` / `h`** | 每个 panel | 版面不是你要的（或跑到看不见的格子里） |
| 6 | **`sessionTitle` / `sessionId` / `pinTarget`** | AI 面板 | 面板不钉会话：显示别的那条，或让用户自己选 |
| 7 | **`<...>` 尖括号占位** | 全部文件 | 全文搜一遍 `<`，一个都别留 |

> 建议：拷完先 **全局搜一次 `<`** 和 `session-0000`，再把场景丢进 `scenarios/` 切一次场景看结果。

## 约定

- 模板里的路径**一律用占位符**，不写死任何人的机器路径；
- 模板不含密钥、账号、二维码、业务数据；
- 每个模板文件顶部写一行注释，说明"改哪几个地方就能用"。
