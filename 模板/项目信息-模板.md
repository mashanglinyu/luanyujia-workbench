## 六、读写协议（§〇 与 §五 就是"无限记忆"的机制）

- **什么时候读**：新会话开场 / 换完会话 / 隔天接手 → 读 **§〇 + §一 + §二**，再读定位卡与技能。
  卡与技能**不要每轮重读**，需要时再 `grep` 定位。
- **什么时候写**（干完活，不等提醒）：
  1. 长期有效的结论 / 决策 / 新坑 → 追加 **§五**（一条一行，带日期）；
  2. 本次进度 / 下一步 / 卡点 → **覆盖 §〇**（旧内容挪进 §五）；
  3. 项目级进度 → 该项目自己的项目信息；
  4. 新踩的坑 / 新流程 → 追加**主技能**；
  5. 同步定位卡「上次进度」一行。
- **会话到线怎么办**：先把 §〇 写好 → 走换会话命令（见 `02-会话定位与跟随/五-换会话与归档.md`）→ 回写配置 → 自检。
  **记忆在文件里，不在会话里，所以会话可以无限换。**
- **权威顺序**：场景记忆（本文件）＞ 定位卡 ＞ 技能叙述；冲突时以前两者为准，并顺手把技能改对。
