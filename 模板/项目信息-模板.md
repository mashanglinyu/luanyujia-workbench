# 场景记忆模板（v2 · 2026-10-27）

> 用途：新场景 / 新项目照抄。旧称「场景项目信息」已并入 **`引擎\场景记忆\`**，旧路径只作兼容链接。
> 分工：`场景私有记忆.md` **人写** ｜ `身份卡.md`、`场景画像.md` **工具生成（⛔ 手改即校验失败）** ｜ `项目记忆\<项目id>.md` 一项目一份。

## 一、`引擎\场景记忆\<场景>\场景私有记忆.md`（≤25 KB，§〇 ≤4 KB）

```markdown
# 场景私有记忆

## 核心职责（≥3 条）
- 负责：<做什么>
- 负责：<做什么>
- 不碰：<边界，谁的地盘>

## §〇 当前交接（≤4 KB）
### 1) 上次交接
- <做了什么 / 结果 / 证据>
### 2) 当前项目
| 项目 | 记忆文件 | 状态 | 下一步 |
|---|---|---|---|
| <项目名> | <项目id>.md | 进行中 | <动作> |
### 3) 私有记忆变更
- <YYYY-MM-DD>：<改了什么 + 为什么>
### 4) 下一步 / 卡点
- 下一步：<谁先动，按什么顺序>
- 卡点：<没有写"无"；有就写清等谁>
### 5) 全貌
- <一两句：这个场景现在是什么状态>

## §一 这个场景是干什么的
## §二 我是谁、开工读什么（面板 / 定位卡 / 技能 / 记忆路径）
## §三 资产地图（主工程 / 凭据（只写路径） / 产物 / 线上 / 只读区）
## §四 项目索引（→ 项目记忆）
## §五 长期记忆（决策 / 铁律 / 坑，只追加）
```

## 二、`项目记忆\<项目id>.md`（≤8 KB，7 字段，`项目.json` 的 `memory` 指到这里）

```markdown
# <项目名> · 项目记忆

> 项目 id：<id> ｜ owner：<场景> ｜ 建单：<YYYY-MM-DD> ｜ 最近更新：<YYYY-MM-DD>

- **状态**：进行中 / 等待外部 / 已结项 / 归档
- **一句话**：这个项目是什么、做到哪了
- **成果/证据**：产物路径、版本、验收结论（可指向 README / 项目信息）
- **下一步**：谁在等谁、下个动作
- **坑**：踩过的、下次别踩的
- **已有档案**：`<项目目录>\README.md` / `项目信息\`（没有写"待补"）
```

> 写回判据：项目有实质进展（交付 / 验收 / 方案定稿 / 换版本）才更新；只改对应字段，不整篇重写。
> ⛔ 不把别人的项目写进来；跨场景结论进 `引擎\场景记忆\_共享记忆\areas\<面板>.md`。
