## 这批实拍图是怎么来的（可复现）

1. **截真窗口**（不是摆拍、不是示意图）：直接抓工作台主窗口的位图；
2. **按坐标打码**：用脚本在图上盖同色方块，打掉这四类 ——
   **金额类**（顶栏资产数字）、**本机路径**（含盘符的目录、凭据目录名）、
   **对话正文**（整段聊天记录，盖上「对话内容已打码」）、**用量统计**（轮次 / token 数）；
3. **裁剪拼接**：需要"分类型看"的图，一律从**已打码的那张**上裁，再按原比例拼版。

> ⚠️ **顺序很重要**：先打码、再裁剪。反过来做一次，就会出现"某张裁剪图里漏了一块没打码的路径"。

## 截图规矩

- **必须抹掉个人内容**：项目名、路径、账号、聊天内容、金额、网址 —— 一律打码或换成占位；
- 统一尺寸与主题（同一套配色，别一张亮一张暗）；
- 图片放进本目录后用相对路径引用，别外链（外链会失效）。
