## 6. 回执双向自动销账（含"长任务必须回执结束"）

| 方向 | 触发 | 实现 |
|---|---|---|
| 我发知悉（我当回执方） | 发消息时**全自动** | `通知场景.mjs` L1037+：发 `【不需要回执` 时，自动销 `from=对方 & to=我` 的最新未 ack 条目（真实链路已验 ✅） |
| 我收知悉（我当发起方） | **每 10 分钟自动**（2026-10-20 加） | `回执哨兵.mjs` 默认扫"对方已回知悉、我未销"的 ⇒ 写 `ack`（note 记来源时间）；手工兜底 `回执收下.mjs [--go]` |
| 对方一直不回 | **超 20 分钟自动催**（2026-10-20 加） | `回执哨兵.mjs` 调 `通知场景.mjs --wake --no-tag` 催对方；≤2 次、间隔 30 分钟；`--no-nag` 关；失败下轮重试（过负载闸） |
| 一条知悉只能销一笔 | — | 防止"回一次销 8 条" |
| 默认只看今天 | — | 历史积压要显式 `--since` |

**规矩**：长任务（多步/跨会话）**干完或卡住都要回执**给发起方；⛔ 只在自家窗口说"我做完了"＝没交付。
**判据**：**"活干完了但对方还不知道" = 没干完**。

**已知弱点（实测）**：
- 台账可能**缺记录**（bv-ai 回了但台账没有）⇒ 自动销账失效，要手工 `--ack`
- `通知场景` 的面板名册**写死**（新场景要加一行，B站 当晚报错过）

## 8. 跨场景回执（"接收方不回执 / 说发了其实没发"）

| 项 | 内容 |
|---|---|
| 规矩 | ① 要对方动手/回答 ⇒ 首行 `【需要回执】`；② 回执只用 `【不需要回执·知悉】`（自动销账，不再回）；③ 收到知悉一个字都不回 |
| **欠账判据** | 台账 `route` 以 RPC 开头且 `RPC n` 的 n≥1（真进会话）+ 未 ack + >10 分钟；`【不需要回执·知悉】` 本身不算欠账 |
| **抓手（全机）** | `回执哨兵.mjs` 每 10 分钟（计划任务 `DSH-回执哨兵`）把欠账面写进 待办板 最前一行（简报每轮注入前 8 条） |
| **抓手（本会话）** | `会话开场简报` 新增 `【回执】` 块：只列"你欠谁、多久、hash、怎么销"，无欠账不出现（⚠ 需重启引擎生效） |
| **核账** | `回执哨兵.mjs --verify <hash前缀>`：直接判"真进会话 / 只落盘 / RPC 全失败" |
| 陈旧账 | 48h 以上不进板；`--stale-report` 出明细；`--expire-hours 96 --go` 才作废（写 ack + 日志，不删记录） |
| 自测 | `回执哨兵` 17/17（RPC0 / 已 ack / 知悉 / 未到阈值 四个反例）· `通知场景` 8/8 · `待回执` 7/7 · 简报插件 7/7 |
| 踩坑 | ① 旧 `回执盯梢` 的 `⚡ 紧急` 段是纯文本，简报只解析 `- [ ] … 状态: ⏳` ⇒ 从没被注入过；② `cmd /c ""prog" …"` 会剥引号**静默不执行**（cscript exit=0 但 node 没起）；③ 简报自测 `countBlockItems` 会把新块里的 `- ` 行算进待办 ⇒ 回执块必须放在【最新通知】之后 |

## 9. 附：本批踩过的坑（写下来防再犯）

1. **PowerShell 里 `$t` 与 `$T` 是同一个变量**（大小写不敏感）⇒ 读文件后路径变量被覆盖，`WriteAllText` 失败（反而救了文件）。**别用仅大小写不同的变量名。**
2. **PS 双引号字符串会解释 JS 的 `` `${}` ``** ⇒ 改 JS 模板串必须用编辑工具，别用 PS 的 `.Replace()`。
3. **`.vbs` 是 UTF-16LE**（现有文件如此）；引号拼接要用变量，别在字符串里直接写 JS 变量名（会当 VBS 变量报错）。
4. **`目录哨兵 --save` 会连带刷新"违规区基线"** ⇒ 把 `<盘根>\360Downloads` 洗白了；已手工摘回。
5. **`--ack <面板> --all` 实测只消一部分** ⇒ 手工销账用**单条 hash** 最稳。
6. **升级 rc.2 后 `deepseek-official/deepseek-flash` 窗口显示 128k**（AGENTS 里记的是 1M）⇒ **长会话瞬间超线**，是"任务断片"的根因之一。⚠ 待确认是否升级带来的回退。
