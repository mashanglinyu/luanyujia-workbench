## A. 形态判定

**结论：混合形态 —— Python Agent 运行时（主体）+ Electron 外壳（apps/desktop）+ TUI/CLI/gateway 多前端。不是 VS Code 分支，不是浏览器扩展。**

关键点：Electron 只是壳，真正的"Agent 运行时 home"是 `HERMES_HOME=<旧位置>\Hermes`（数据/配置/技能/记忆），
源码在 `hermes-agent\`（Python 3.14，uv 管理），前端有 3 套并存：`apps/desktop`（Electron）、`ui-tui`（TS TUI）、`web`（dashboard）。

| 判据 | 证据 |
|---|---|
| Python 包根 | `hermes-agent/pyproject.toml:5` `name = "hermes-agent"`；`:16` `requires-python = ">=3.11,<3.15"` |
| Electron 外壳 | `hermes-agent/apps/desktop/package.json:4` `"description": "Native desktop shell for Hermes Agent."`；`:14` `"main": "dist/electron-main.mjs"` |
| 启动器是 exe shim | `bin/hermes.exe` 115,028 B；`Hermes.cmd:4` `set "HERMES_HOME=<旧位置>\Hermes"` |
| gateway 常驻进程 | `gateway_state.json:1` `{"pid":25852,"kind":"hermes-gateway",...}` |
| 非 VSCode 分支 | 无 `product.json`、无 `resources/app/out/**`；`hermes-agent/.git` 是源码仓库 |
| 非扩展 | 无 `manifest.json`（浏览器扩展形态）；`tools/` 里放的是**下载下来的二进制**（node/uv/ripgrep/ffmpeg/git/chromium），不是自家工具代码 |

## C. 明文区（可直接读的规格）

1. **`config.yaml` 113KB**：几乎每个键都有 3–10 行注释解释默认值、边界、踩坑历史（含 issue 编号）。这是最高性价比的证据源。
2. **模块 docstring**：本项目 docstring 写得像 ADR，直接给出"为什么这么做 + 失败过什么"。例：`agent/micro_compaction.py:5` "OFF by default: every pass rewrites the prompt prefix and breaks the provider prompt cache."
3. **`tools/threat_patterns.py`**：注入正则表全明文，含 scope 分层理由。
4. **`hermes_cli/kanban_workflow.py`**：看板列 + 手动迁移矩阵，纯数据。
5. **`agent/compaction_events.py`**：压缩遥测的封闭枚举（kind/trigger/outcome/failure_class）。
6. **`install.ps1` 87KB**：安装分阶段协议（`-Stage NAME -Json`），是"可被外部编排"的安装器契约。
