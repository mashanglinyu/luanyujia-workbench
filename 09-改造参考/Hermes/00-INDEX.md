**形态**：Python 3.14（`hermes-agent/`，uv）+ 多前端（Electron/TUI/web）。非 VS Code 分支。

## 七条最重要结论

1. **压缩是四级阶梯**（prune → micro → summarize → provider_native），前三档默认关；只抄等级不抄默认值 → 省钱反涨账单。   
2. **注入防线三个洞**：围栏工具名不含 `delegate_task`/`terminal`/`read_file`；36 条英文模式对中文召回 **9%**；BOM 被判成攻击（语料 16.2% 误报），只扫前 64KB。
3. **任务实体是地基**：`claim_lock`/`worker_pid`/`heartbeat`/`consecutive_failures` 支撑"崩了续跑"。DSH 缺它。
4. **迁移的坑不在迁移，在盖章**：单步失败只记 warning，版本号照盖到最新 → 该步永久跳过。
5. **失败不是一个错误，是 29 个原因**：403 分出 auth/billing/WAF/内容策略四义。
6. **"完成"靠证据不靠声明**：退出码归因 → 台账 → 停止闸。DSH 只信自述。
7. **本地模型不是换个 base_url，是一层运维**：`health 200` 不算就绪；窗口是解出来的不是配的。DSH 只判 `127.0.0.1`。
