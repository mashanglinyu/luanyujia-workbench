# 执行层方案对比：让 AI 真的操作电脑（2026-11）

> 目标：解掉「执行层靠人、靠像素」——不是多点几下鼠标，而是把操作变成**可控、可读回、可复用**的能力。
> 口径：只做方案对比，不推荐直接上生产；每项给许可/依赖/GPU/能否做成原生工具/最小验证。
> 元数据：2026-11-01 经 GitHub API 实读（star / 许可 / 最近推送）。本页核对日期：2026-11-01


## 读完你能做到（3 条）

1. 用 **5 个判据**快速淘汰方案：许可是否传染、依赖是否可常驻、要不要 GPU、能不能读回、权限面多大。
2. 知道**先做控件级（UIA），像素只做兜底**——不是所有"AI 操作电脑"都该上视觉模型。
3. 复制表里**6 条最小验证命令**，十分钟内自己判断一个方案在你机器上跑不跑得起来。

### 5 问淘汰表（抄走就能用）

| 问题 | 答"否"的后果 |
|---|---|
| 许可证允许我商用/分发吗？ | AGPL 会拖累整个产品 |
| 依赖能长期常驻吗（不是一次脚本）？ | 每次都要重装环境 = 不可用 |
| 需要 GPU 才能用吗？ | 没显卡的机器直接出局 |
| 操作后能读回验证吗？ | "点了"不等于"生效" |
| 默认权限是不是过宽？ | 越宽越需要沙箱与人审 |

## 一、六条路线

| 方案 | 许可 | 依赖 | GPU | 能否做成原生工具 | 最小验证 | 定位 |
|---|---|---|---|---|---|---|
| `pywinauto` | BSD-3 | Python + Windows UIA/Win32 | 无 | 能（CLI） | `python -c "from pywinauto import Desktop; print(len(Desktop(backend='uia').windows()))"` | 控件级操作（稳） |
| `uiautomation` | Apache-2.0 | Python + Windows UIA | 无 | 能（CLI） | `python -c "import uiautomation as a; print(a.ControlFromCursor().Name)"` | 控件级操作（轻） |
| `dsh-computer-use` | MIT | Windows + PowerShell + UIA | 无 | 能（原生插件） | 装测试 profile 后跑「截图→列窗口→找元素」三条 | 工具层「手+眼」 |
| `OmniParser` | CC-BY-4.0（权重） | Python + PyTorch + 权重 | 建议 GPU | 部分（服务） | `python -c "import torch; print(torch.cuda.is_available())"` | 视觉解析（像素兜底） |
| `UI-TARS-desktop` | Apache-2.0 | TS/Electron + 模型 | 需模型 | 部分（独立 app） | `npm i && npm run dev`（需模型端点） | 端到端 GUI agent |
| `browser-use` | MIT | Python + 浏览器 + LLM | 无 | 部分（服务） | `pip install browser-use && python -c "import browser_use; print(browser_use.__version__)"` | 浏览器执行层 |

## 二、我们的判断

1. **优先做「控件级」而不是「像素级」**：UIA 路线（`pywinauto` + `uiautomation`）无模型、无 GPU、当天可验，且能**读回控件名**做自证——这是去像素化最直接的一刀。
2. **像素只做兜底**：UIA 树不全的应用（部分 Electron / 自绘界面 / 游戏）才上截图+视觉模型；`OmniParser` 属于这一类，有 GPU 再考虑。
3. **新插件要审**：`dsh-computer-use` 看起来最贴（原生插件、25 工具、零模型），但**星数极低 + 逆向契约 + 默认宽松权限**，必须先审代码、只跑测试 profile，跑赢再替换主力。
4. **重方案不进分发**：`UI-TARS` / `browser-use` / `Skyvern` 都要模型或独立 runtime，适合当独立服务调用，不适合塞进产品仓库。

## 三、判定标准（可复用）

| 维度 | 为什么重要 |
|---|---|
| 许可 | AGPL 有传染性，会拖累整个分发；商业软件不能拆 |
| 依赖 | 是否需要 GPU / 模型 / 浏览器内核，决定能不能常驻 |
| 可读回 | 操作后能不能验证「真的生效」——比"点到了"重要 |
| 权限面 | 默认权限越宽，越需要沙箱与审批 |
| 维护度 | 最近推送时间 + 星数只是代理指标，仍要读代码 |
