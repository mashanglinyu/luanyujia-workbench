# 单场景自我进化：一条最小闭环（公开版）

> 这一页只讲**闭环的形状 + 三件能跑的事 + 边界**；不给阈值、不给自动归纳与验证闸的实现。
> 配图：[`配图/单场景自我进化-最小闭环.svg`](../配图/单场景自我进化-最小闭环.svg) · 核对日期：2026-11-04

## 一、为什么是「场景」而不是「一套大记忆」

一个场景 = 一个工人。工人要越干越强，靠的不是更长的提示词，而是**它自己的记忆、技能、画像每轮都在被写回**。
所以闭环的单位是**场景**，不是全局：每个场景有自己的私有记忆、定位卡、技能与画像，彼此不串。

## 二、链条长什么样

```
场景 1 ─┬─ 场景私有记忆（含核心职责，人写）
        ├─ 定位卡（这个场景管什么，人写）
        ├─ 私有技能（自动进化 —— 公开版留白）
        └─ 场景画像（工具生成，不手改）
           │
           ▼
         会话 ──当前交接──▶ 归档备份（历史会话 / 旧版记忆，只进不改）
           │
           ├──▶ 项目 1 信息
           └──▶ 项目 2 信息
                     │
                     ▼
                 验证闸（公开版留白）   自动归纳（公开版留白）
```

**关键点**：记忆**落文件**、不落会话；交接是**覆盖写**，旧版**必归档**；项目信息与场景记忆分开存。

## 三、能跑的三件事（公开版已带工具）

| 事 | 做什么 | 判据（原则，不给阈值） |
|---|---|---|
| **① 记忆生成** | 给场景建目录骨架：私有记忆 / 身份卡 / 场景画像 + 项目记忆 | 三份文档必须在；画像只能工具生成，手改即校验失败 |
| **② 交接** | 归档旧版 → 覆盖写 §〇 四小节（进度 / 下一步 / 卡点 / 待办）→ 重生成卡与画像 → 登记索引 | 交接后新会话读 §〇 就能接上；索引只追加，不删别人的行 |
| **③ 归档** | 旧版进 `归档\`，只进不改 | 可回滚；不为了“干净”删证据 |

工具就在公开包里：`工具\场景记忆.mjs`（`init` / `交接` / `check` / `list`），路径可用 `--root` 或环境变量 `DSH_SCENE_MEMORY` 指到你自己的目录。

## 四、公开版**没有**的两件（也是成品版的价值所在）

1. **自动归纳**：从对话里提“候选写回”，再经人审并入记忆。没有它，记忆要靠人手写——这就是“越用越强”的速度差。
2. **验证闸**：硬判据 + 反例清单 + 检查脚本，保证改完不会悄悄退化。没有它，写得越多越可能坏。

> 公开链条图与三件事，是因为**方法该被看懂**；实现留白，是因为**速度与保险才是护城河**。
> 我们的判断：开源不可逆——图可以送，发动机和刹车不送。

## 五、别人在自己机器上跑起来，只需要改三处

| 要改的 | 默认 | 改法 |
|---|---|---|
| 工作台根目录 | 脚本上一级 | `--root <你的根>` 或 `DSH_SCENE_MEMORY` |
| 引擎 / `.dsh` | `<根>\引擎` | `DSH_HARNESS_DIR` / `DSH_HOME` |
| 日志与界面地址（建会话用） | `<根>\外壳\server.log` · `http://127.0.0.1:3080` | `DSH_LOG` / `DSH_GUI_BASE` |

另外一条**场景假设**：面板 id 建议**与场景 id 一致**（建会话脚本按它找场景），不一致时要手改 `scenarios\<场景>.json` 里的 `sessionId` / `sessionTitle`。

## 六、明确不公开

- 自动归纳的触发条件与写回策略、验证闸的具体判据与脚本、技能自动进化的回写/淘汰/版本机制
- 内部路径约定、台账结构、私有记忆的真实内容
