# 对标：一款商业「本地 AI 伙伴」（Aivy OS）

> 对标对象：`Bo1202/Aivy-OS`（GitHub 公开仓库 **只放文档与 Releases**，软件本体为**商业授权**）。
> 本页只提炼**机制**，不复制代码、界面、文案、图标。核对日期：2026-11-01

## 一、它做了什么（公开 README 事实）

- Windows 上的本地 AI 伙伴：语音对话、**可随时插话打断**（先压低再确认）、长期记忆 + 独立**用户画像**
- 能读写文件、跑程序、看屏幕/认控件/点按钮，**操作后读回核对**
- 改动按时间记录，**可撤回**
- 子智能体并行；内置 IDE；MCP；多模型随时切换（含本地模型）

## 二、我们抄哪 4 个机制

| 机制 | 为什么值得抄 | 我们的落法（方案级） |
|---|---|---|
| **语音插话判定**：播报中检测人声 → 快速降低音量 → 确认是人声才停 → 说完续播 | 打断体验是"像人"与"像机器"的分水岭 | 引擎侧流式 ASR + 外壳侧 ducking/VAD 分两层做 |
| **画像单独一份**：称呼/习惯/语气单独存，每次注入 | 比混在大记忆里省 token、也更稳定 | 共享层单独一份画像，由人审后更新 |
| **操作后读回自证** | "点了" ≠ "生效" | 执行层统一「操作→读回→不一致就报错」 |
| **改动可撤回** | 敢让 AI 动手的前提 | 一次操作一条可撤回记录（快照 + 摘要） |

## 三、我们明确不抄

- 界面、图标、文案、产品名：商业软件版权，一律不复制
- "数字生命体/人设"层：我们定位是**生产工具**，不做陪伴人设
- 它的商业模式与分发方式：与我们无关

## 四、判断

1. 这类产品证明了一件事：**"会动手 + 有记忆 + 可撤回"是用户真正感知到的能力**，而不是模型分数。
2. 我们的差异点不在功能清单，而在**可拆、可私有化、可被别人拿去改**——这是开源路线与商业软件的根本区别。
3. 复刻顺序应该是：**可撤回 → 读回自证 → 语音打断 → 画像演化**（先安全，再顺手，再拟人）。
