# 从零到能跑 —— 六步，每步都有验收标准

> 这一篇只管一件事：**按顺序把一台能用的工作台立起来**。
> 每一步都写清"看到什么才算过" —— 没验收标准的步骤，等于没做。

---

## 第 0 步：先接受三个前提

| 前提 | 意味着 |
|---|---|
| **它是源码直跑，不打包** | 改界面代码靠"重载"，改主进程靠"重启"；⛔ 别打包（会毁掉联接形态） |
| **引擎不注入场景** | "我是哪个场景"要靠索引表 + 定位卡认领（见 [`../00-核心机制/三-场景体系.md`](../00-核心机制/三-场景体系.md)） |
| **记忆在文件里** | 会话会被换掉；没有 `§〇 交接` 就等于没记忆 |

---

## 第 1 步：把"壳"跑起来（不接 AI）

```bash
# 你的桌面壳（Electron 或等价物）
pnpm install
pnpm start        # 或 electron .
```

**验收**：出现一个窗口，**能切到至少 2 个场景**，每个场景里能看到面板（哪怕是占位）。

> 这一步不过，后面全都白搭 —— 先别碰会话、别碰 MCP。

---

## 第 2 步：定义你的第一个场景

按 [`../01-场景模式/场景配置格式.md`](../01-场景模式/场景配置格式.md) 写一份 `<id>.json`，
面板先只放一个 **占位面板**（不接 AI），位置按网格填。

**验收**：

- [ ] 标签栏出现这个场景（**文件名 = id**，否则不出现）
- [ ] 点它，中间出现你摆的面板，位置对
- [ ] 没有出现"未知面板类型"的灰字（出现 = `type` 没注册）

---

## 第 3 步：把一条 AI 会话绑上去

三个字段缺一不可（详见 [`../02-会话定位与跟随/二-会话绑定三字段.md`](../02-会话定位与跟随/二-会话绑定三字段.md)）：
`sessionId`（精确）· `sessionTitle`（人读）· `pinTarget`（兜底）。

**验收**：

- [ ] 切到该场景，AI 面板里是**那一条**会话（不是空白、不是别人那条）
- [ ] 连着切三个场景再切回来，**还是同一条**（不串台）
- [ ] 重启工作台后，**仍然**是同一条

> 三条里最容易失败的是第三条：说明会话 id 是"临时找的"而不是配置里写死的。

---

## 第 4 步：给它一份"身份"和一份"记忆"

照 [`../05-协作与规矩/四-身份索引-怎么建.md`](../05-协作与规矩/四-身份索引-怎么建.md) 建索引表一行；
照 [`../模板/定位卡-模板.md`](../模板/定位卡-模板.md) 写定位卡；照 [`../模板/项目信息-模板.md`](../模板/项目信息-模板.md) 写 `§〇 交接`。

**验收**：

- [ ] 新开一条会话，只给它"去读索引表 + 定位卡 + §〇"，它能说出：**我是谁、上次干到哪、下一步干什么**
- [ ] 说不出来 ⇒ 你的卡或 `§〇` 写的是形容词，不是事实

---

## 第 5 步：装自检（这一步别省）

| 自检 | 查什么 | 什么时候跑 |
|---|---|---|
| 入口哨兵 | exe 是否被换过、`resources\app` 是否还是**联接** | 每次改壳之后 |
| 会话自检 | 每个面板的 `sessionId` 是否命中 | 每次换会话之后 |
| 面板重载 | 改 `renderer` 后能否热生效 | 每次改界面之后 |
| 日志看门 | `server.log` 里有没有 `launch-failed` | 面板变白时第一件事 |

**验收**：故意改坏一处（比如把某个 `sessionId` 改成不存在的），自检**必须报出来**。
报不出来 = 你装的是装饰品。

---

## 第 6 步：开始用，并且写回

每天收工前做三件事（10 分钟）：

1. **进度写回 `§〇`**（覆盖，不是追加）；
2. 新踩的坑 → 场景记忆的 `§五`（一行一条：症状 / 根因 / 怎么修）；
3. 新流程 → 写进该场景的技能。

**验收**：第二天新开一条会话，**不看昨天的对话**，只读 `§〇` 就能接着干。

---

## 时间预期（诚实版）

| 阶段 | 只做"能跑" | 做到"顺手" |
|---|---|---|
| 壳 + 场景 | 半天 | 2~3 天（面板类型会越加越多） |
| 会话绑定 + 身份 | 2 小时 | 一天（索引表与卡要写全） |
| 自检 | 2 小时 | 一周（边踩坑边补检查项） |
| 多会话协作 | — | 等你真开了 3 个以上再上（见 `00-核心机制`） |

> ⚠ 最常见的失败：**第一天就想把 10 个场景全配好**。
> 正确做法：**先一个场景跑通全链路**（壳→场景→会话→身份→记忆→自检），再复制第二、第三个。
