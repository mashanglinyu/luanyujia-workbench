# 自检清单 —— 改完必跑的那几项

> 这份清单的用途不是"求安心"，而是**在你要宣布"好了"之前，先用机器否一次**。
>
> 前提判据（来自真实教训）：**永远通过的检查 = 装饰品。**
> 每一项都要能回答："如果它坏了，这一项会怎么报？"

---

## 1. 四类改动，四套自检

| 你改了什么 | 必跑 | 通过标准 |
|---|---|---|
| **界面渲染层**（`renderers.js` / `styles.css` / 场景 json） | 面板重载 | 目标场景面板刷新后行为正确，**其它场景不受影响** |
| **壳主进程**（`main.js` / `preload.js` / `renderer.js`） | 重启后跑：入口哨兵 + 会话自检 | exe 哈希未变 · `resources\app` 仍是联接 · 每个面板 `sessionId` 命中 |
| **引擎**（源码 / 插件 / 配置） | 升级前后各一次（`engine-before` → 构建 → `engine-after`） | 升级前有回滚包 · 升级后技能/工具/会话都在 |
| **对外发布**（仓库 / 站点） | 敏感词扫描 + 链接检查 | 关键词 0 命中 · 坏链 0 |

---

## 2. 每次改完都该跑的四条

```
① 入口哨兵     —— exe 有没有被换/改名；resources\app 还是不是联接
② 会话自检     —— 逐面板打印"✓ id 命中（身份校验通过）"
③ 面板重载     —— 目标场景 ⟳ 之后行为正确
④ 看日志       —— server.log 里有没有 launch-failed / 报错堆栈
```

> ①③ 是"壳层健康"，② 是"绑定健康"，④ 是"有没有静默失败"。

---

## 3. 面板变白时的排查顺序（别跳步）

```
1. server.log 找 launch-failed        → 有 ⇒ 壳的问题（可能 exe 被换过）
2. 确认 exe 是原来那个（哈希）         → 变了 ⇒ 别改名/别替换，请机主重启
3. 面板重载（all）                    → 好了 ⇒ 只是渲染层没刷新
4. 控制台看单个面板的报错              → 有 ⇒ 该面板渲染器的问题
5. 最后才请机主重启工作台
```

> ⛔ 顺序颠倒的代价：先重启了，**证据就没了**，下次还会再犯。

---

## 4. 换会话后（必须同步三处）

| 处 | 改什么 |
|---|---|
| 场景配置 | `sessionId` / `sessionTitle` |
| 身份索引 | 该面板的会话 id 列 |
| 场景记忆 `§〇` | 交接署名（"本会话 id 于 <日期> 改写"） |

**验收**：`sessions --check` 逐面板全绿；连着切 3 个场景再回来，仍是同一条会话。

---

## 5. 对外发布前（仓库 / 站点）

| 检查 | 判据 |
|---|---|
| 敏感词 | 客户名 / 人名 / 邮箱 / 站点 / 公网 IP / 真实会话 id / 盘符路径 / 密钥格式 ⇒ **0 命中** |
| 链接 | 相对链接全部可达（坏链 0）· 目录链接都能落到有 README 的目录 |
| 图片 | 引用的图都在，且**打码过**（金额/路径/对话正文/用量） |
| 占位符 | 全文没有 `<...>` 之外的私名残留（作者署名除外） |
| 数据 | JSON 全部可解析 |

> 建议顺序：**先扫描、再提交、最后推**；推完用"远端 hash == 本地 hash"验证（见 [`../../模板/`](../../模板/) 同级的推送脚本思路）。

---

## 6. 自检本身的三个反模式（都会让检查变成摆设）

| 反模式 | 为什么假 |
|---|---|
| **没有反例** | 永远通过 ⇒ 你不知道它会不会报。造一个必然失败的样本，确认它会报 |
| **只给一个 0** | 结论说不出"差异集合" ⇒ 你无法判断它到底比了什么 |
| **把被检对象写进白名单** | "自己检查自己"必然合格 |

> 判据：**一条自检必须能说出"我比了什么、差在哪"，否则它只是打印了一行绿字。**

---

## 7. 一周一次（慢变量）

| 项 | 为什么单独列 |
|---|---|
| 会话库体积 / 记忆是否超线 | 慢慢变胖，平时看不见；到线才被动处理 |
| 备份能不能恢复 | **没演练过的备份等于没有备份** |
| 依赖/版本漂移 | 上游变了，你的选择器/字段可能悄悄失效 |
| 索引死条目 | 文件删了、索引还留着 ⇒ 下次照着索引找会白跑 |
