# 配置片段

> **这个文件干什么**：把「工作台里真正写过的配置」摘出来，删掉路径与名字，留下结构。
> 照着改的时候只改**值**，别改**结构** —— 结构错了程序不报错，只是静默不生效。

> ⚠️ 全篇 `<DSH根>` `<工作区>` `<外壳>` 都是占位符，换成你自己机器的路径。

---

## 一、profile 补丁层：插件怎么挂上去

引擎侧的插件不在代码里注册，而是写进 **profile 的补丁层**（每次启动按顺序叠上去）。

文件：`<DSH根>\引擎\.dsh\profiles\web\cordis.patch.yml`

```yaml
# 顶层是一个 YAML 数组，每一项是一次"加载器补丁"
- insert:
    - id: deepseek-balance-host          # 插件实例 id（唯一，别和别人的重名）
      name: dsh-plugin-deepseek-balance   # npm 包名 / 本地目录名
    - id: boot-anim-host
      name: dsh-plugin-boot-anim
      config:                             # 需要参数的插件才写这段
        mode: auto
        db: '<DSH根>\外壳\data\记忆库.db'
        max: 5
```

**三个要点**

| 要点 | 说明 |
|---|---|
| `id` 唯一 | 两个插件用同一个 `id`，后加载的会顶掉前一个，而且**不报错** |
| 卸载 = 删两行 | 删掉 `- id` / `name` 两行，再重启；插件目录可以留着 |
| 改了要重启 | 补丁层只在启动时读一次 —— 这是少数**必须重启**的改动之一 |

### 想临时关掉而不卸载

很多插件支持运行时开关（写在 `localStorage` 或自己的配置文件里）。原则：
**配置能热更的，别做重启方案** —— 具体的键名看各插件 README。

## 二、MCP 服务器：怎么接一个外部能力

MCP 不是插件，是**独立子进程**，通过标准协议通信。配置一般长这样：

```json
{
  "mcpServers": {
    "<服务器名>": {
      "command": "<可执行文件或解释器>",
      "args": ["<入口脚本>"],
      "env": { "<变量名>": "<值>" }
    }
  }
}
```

**三条踩过的坑**

1. **按需才拉，不常驻**：每个 MCP 都会占上下文（工具描述算 token）。实测一个 `cua-driver` 就吃 26.8k/轮 —— 平时关着，要用再开。
2. **`command` 要写绝对路径**：写 `node` 在图形界面启动的环境里可能找不到（PATH 不一样）。
3. **子进程不继承你的环境变量**：需要的 key 必须在 `env` 里显式给。

## 三、场景卡：面板怎么摆

场景 = 一张 JSON，描述「这个场景有哪几块面板、每块占几行几列、AI 那块钉哪个会话」。

```json
{
  "id": "<场景id>",
  "name": "<中文名>",
  "layout": "grid",
  "theme": "dark",
  "panels": [
    { "id": "p1", "title": "预览", "type": "view",
      "col": 1, "row": 1, "w": 3, "h": 2 },

    { "id": "p2", "title": "AI·<场景>", "type": "harness",
      "sessionTitle": "<会话名>",
      "sessionId": "session-0000-0000-0000-0000-000000000000",
      "col": 2, "row": 3, "w": 3, "h": 2 }
  ]
}
```

**坐标规则**：`col/row` 从 1 开始，`w/h` 是占几格；一个 4×4 网格里，`col:4,w:1` 就是最右一列。

**三个坑**

| 坑 | 症状 | 正确做法 |
|---|---|---|
| `sessionId` 写了别人的 | 面板打开是别人的对话，甚至串话 | 每台机器自己生成；占位用 `session-0000…` |
| 面板 `type` 写错 | 面板显示「未知类型」或整块空白 | 只写你在 `外壳/renderer` 里注册过的 type |
| `w/h` 超出网格 | 面板被挤到下一行，看着"少了一块" | 先算总列数，再分配 |

## 四、环境变量：换机器必改的两个

| 变量 | 作用 | 不设的后果 |
|---|---|---|
| `DSH_HOME` | 会话、技能、配置都在这下面 | 读到旧机器的会话库 |
| `DSH_SHELL_DIR` | 外壳（工作台本体）在哪 | 插件找不到外壳，只能显示兜底 |

这两个是**路径类配置**：改完必须 `Test-Path` 验一遍，别只看"长得对"。

## 五、启动链路里各自改什么要重启

| 改什么 | 生效方式 | 代价 |
|---|---|---|
| 技能 / 引擎配置 | 热生效 | 0 |
| 渲染层面板（`renderers.js`、样式） | 有面板自刷新通道 | 一次刷新 |
| 主进程 / 预加载 / 新插件行 | **必须重启** | 当前会话全断 |
| 启动器 exe | ⛔ 不要改 | 面板全灰白（见 [踩坑总表](踩坑总表.md)） |

> 判断标准：**这件事机器自己能不能做？能就别交给人。**
