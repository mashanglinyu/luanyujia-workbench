# 05 · 顶栏同款（7 个部件）

> 顶栏 = 窗口最上面那一条 + 它下面的场景切换条。这套工作台的顶栏有 7 个部件，**功能清单在这里，实现位置也在这里**。
> 换外壳/换机器后照这张表补，就能得到"同款"。⛔ 改外壳前先备份。

| # | 部件 | 长什么样 | 干什么 | 实现在哪（参考实现） |
|---|---|---|---|---|
| 1 | **品牌名** | 资料 README 里那个名字 + 版本浮层 | 认出这台是谁的 | 外壳前端 `#titlebar .brand` |
| 2 | **5 个网页端按钮** | 品牌名右边 5 个小图标 | 豆包 / 通义 / DeepSeek / 智谱 / Kimi，点一下开内置窗口，再点收起 | 前端里注入 `#webai-strip`（见 `网页按钮.js`） |

| 4 | **场景刷新 ⟳** | 一个 ⟳ | 热更新当前场景的渲染器，**不打断对话** | 顶栏 `#btn-refresh` |

## 一、5 个网页端按钮（网页版 AI）

### 站点表

| key | 名字 | 图标文件 | 强项 |
|---|---|---|---|
| `doubao` | 豆包 | `renderer\assets\webai\doubao.png` | 生图 / 生视频 / 日常问答 |
| `tongyi` | 通义千问 | `renderer\assets\webai\tongyi.png` | 生图（备选）/ 中文长文 |
| `deepseek` | DeepSeek | `renderer\assets\webai\deepseek.png` | 写代码 / 推理 |
| `chatglm` | 智谱清言 | `renderer\assets\webai\chatglm.png` | 写代码（主力）/ 结构化输出 |
| `kimi` | Kimi | `renderer\assets\webai\kimi.png` | 长文（实测输入框有时打不进） |

### 行为约定（照这个做才和原版一致）

- **点一下开**：首次点击创建一个**独立的**内置窗口（webview），登录状态各窗口独立、互不影响；
- **再点收起**：不是销毁，是收起来（下次点回来**不用重新登录**）；
- **同时开**：5 个窗口互斥的关系**不存在**——可以同时开着（每个是一块独立 webview）；
- **图标用官网 favicon**（180×180 PNG），不要用 emoji 凑；图片挂了才退回单字。

### 放哪

注入到 `#titlebar` 里、紧跟品牌名后面（`brand.nextSibling`），DOM 结构：

```html
<span id="webai-strip" class="webai-strip">
  <button class="webai-btn" data-key="doubao"  data-st="none" title="豆包（点一下开一个窗口，再点收起）"><img src="assets/webai/doubao.png" alt="豆包"></button>
  … 其余 4 个
</span>
```

⚠ **幂等**：场景刷新/热更新会重跑注入代码，`#webai-strip` 只许存在一份（先查再建）。

## 二、负载胶囊（CPU / GPU / 内存）

- 位置：顶栏右侧（`⟳` 左边），DOM：`<button id="tbs-load" class="tbs-pill tbs-load">`，内含三个 `.tbs-txt`：
  `CPU <b>10%</b>` · `GPU <b>9%</b>` · `MEM <b>42%</b>`
- 数据来源：外壳主进程读本机负载（性能计数器 / 显卡工具），**渲染层只拿数值**，不直接碰 WMI/驱动；
- 刷新：**有窗口可见才轮询**（隐藏时不轮询，省电），间隔 3–5 秒；
- 着色：CPU ≥70% 黄、≥90% 红；点开可看明细（各进程占用、GPU 显存）。

## 三、场景刷新 ⟳

- 行为：**重跑当前场景的渲染器 + 重读场景 json**，不重启引擎、不中断对话；
- 什么时候用：改了场景 json / 面板样式 / 面板脚本之后，点一下就能看到效果；
- 注意：`renderer\renderer.js`、`main.js`、`preload.js` 这种主进程/预加载脚本**改了必须重启工作台**，⟳ 不管用。

## 四、插件 / 技能 / 工具 / 模型

| 按钮 | 图标 | 点开看到 |
|---|---|---|
| 插件 | 🧩 | 已装插件列表（名字 / 版本 / 状态） |
| 技能 | ✨ | 技能目录（每个技能：名字 / 触发词 / 路径） |
| 工具 | 🛠 | 引擎原有工具 + 插件新增工具（名字 / 位置 / 一句话说明） |
| 模型 | 🤖 | 模型与提供方（当前用哪个、可切换哪些） |

原版还会在这四个右边放 `⚙ 设置`、`📁 文件夹`、`…` 菜单——新版精简掉了，**这 4 个按钮就是核心**。

## 五、余额

- 位置：场景切换条右侧，DOM `<button id="balance-chip" class="balance-chip">¥ …</button>`
- 取值：**主进程**用配置里的 DeepSeek 密钥查平台余额，渲染层只显示数值（⛔ 密钥永不进前端）；
- 悬停：显示「充值 / 赠送 / 可用」明细；余额不足给 ⚠；点击打开用量页；
- 失败：显示 `¥ …` 并在 title 里写失败原因，**不许静默**。

## 六、「正在工作」光效

- 判定：该场景的会话**正在跑**（有未完成的步骤 / 有排队调用）⇒ 给这个场景的标签加 `tab-working` 类；
- 观感：图标发光 + 标签一圈呼吸光环，1.8 秒一个循环；
- 浅色主题自动调暗；系统开了「减少动态效果」就只留静态光不呼吸。

## 七、装完怎么验

| 验什么 | 怎么做 | 期望 |

| ⟳ | 改一个场景 json 的标题，点 ⟳ | 标题变，对话不断 |
| 四个按钮 | 逐个点 | 弹窗都有内容，不空白 |
