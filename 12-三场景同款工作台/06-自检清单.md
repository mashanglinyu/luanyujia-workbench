# 06 · 装完自检清单（8 条，逐条打勾）

> 每条都能一条命令验；不通过就别往下走。
> 下面 `<外壳>` = 你的工作台外壳目录，`<引擎>` = DSH 引擎目录。

## 1. 三个场景文件都在，且是合法 JSON

```powershell
$s = "<外壳>\scenarios"
foreach($f in "self-review","pc-cleanup","design-misc"){
  $p = Join-Path $s "$f.json"
  if(!(Test-Path $p)){ "✗ 缺文件: $f"; continue }
  try { $null = Get-Content $p -Raw -Encoding UTF8 | ConvertFrom-Json; "✓ $f.json 合法" }
  catch { "✗ $f.json 不是合法 JSON: $($_.Exception.Message)" }
}
```

## 2. 场景 id / 名字没撞车

```powershell
Get-ChildItem "<外壳>\scenarios\*.json" | ForEach-Object {
  $j = Get-Content $_.FullName -Raw -Encoding UTF8 | ConvertFrom-Json
  "{0,-28} id={1} name={2}" -f $_.Name, $j.id, $j.name
}
```
期望：`self-review / pc-cleanup / design-misc` 各一行，**id 不重复**。

## 3. 三张身份卡都在

```powershell
foreach($f in "self-review-context.md","pc-cleanup-context.md","design-misc-context.md"){
  $p = Join-Path "<外壳>\scenarios" $f
  if(Test-Path $p){ "✓ $f" } else { "✗ 缺 $f" }
}
```

## 4. 三份场景记忆都在

```powershell
foreach($n in "自我复盘","本地电脑","设计杂活"){
  $p = "<引擎>\场景项目信息\$n\项目信息.md"
  if(Test-Path $p){ "✓ $n 记忆存在" } else { "✗ 缺 $n 记忆" }
}
```

## 5. 会话 id 已回填（不能还是 `__待填__`）

```powershell
Select-String -Path "<外壳>\scenarios\*.json" -Pattern "__待填__"
```
期望：**一条都搜不到**。
如果还有，回到 `01-给DSH的提示词.md` 第五步：先建同名会话，再把真实 id 填进 `sessionId`。

## 7. 重启后三个标签都在，顶栏按钮齐

关掉工作台窗口重开（**不是重启引擎**），检查：

- [ ] 场景条上出现 **自我复盘 / 本地电脑 / 设计杂活** 三个标签，点开不报错
- [ ] 顶栏品牌名右边有 **5 个网页端按钮**，点一个能开窗口
- [ ] 顶栏有 **CPU / GPU / MEM** 胶囊，数字在变
- [ ] **⟳** 能刷新当前场景
- [ ] **🧩 ✨ 🛠 🤖** 四个按钮点开都有内容
- [ ] **¥ 余额** 有数字（或悬停能看到失败原因）
- [ ] 让某个场景跑一个任务，它的标签开始**呼吸发光**

## 8. 三个面板打开都有东西

| 场景 | 点开应有 |
|---|---|
| 自我复盘 | 左上预览、右上文件树、左下网页、右下 AI 会话 |
| 本地电脑 | 盘占比环、大户排行、可清理体检、清理台账、AI 会话 |
| 设计杂活 | 预览、文件浏览、项目管理（预留）、AI 会话 |

任何一块显示「面板类型未知」⇒ 你的外壳不支持这个 `type`，去场景 json 里把这一块换成
`review-doc` / `file` / `harness` / `reserved` 其中之一，再点 **⟳**。

## 附：一键自检（把上面 1/2/3/4/5 合并）

```powershell
$shell = "<外壳>"; $engine = "<引擎>"
$ok = 0; $bad = 0
function chk($cond, $msg){ if($cond){ "✓ $msg"; $script:ok++ } else { "✗ $msg"; $script:bad++ } }

foreach($f in "self-review","pc-cleanup","design-misc"){
  $p = Join-Path $shell "scenarios\$f.json"
  $valid = $false
  if(Test-Path $p){ try { $null = Get-Content $p -Raw -Encoding UTF8 | ConvertFrom-Json; $valid = $true } catch {} }
  chk $valid "场景 $f.json 合法"
}
foreach($f in "self-review-context.md","pc-cleanup-context.md","design-misc-context.md"){
  chk (Test-Path (Join-Path $shell "scenarios\$f")) "身份卡 $f"
}
foreach($n in "自我复盘","本地电脑","设计杂活"){
  chk (Test-Path (Join-Path $engine "场景项目信息\$n\项目信息.md")) "记忆 $n"
}
$left = (Select-String -Path (Join-Path $shell "scenarios\*.json") -Pattern "__待填__" -ErrorAction SilentlyContinue | Measure-Object).Count
chk ($left -eq 0) "会话 id 已回填（残留 $left 处）"

"—— 通过 $ok 项 / 失败 $bad 项 ——"
```
