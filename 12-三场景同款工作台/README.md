# 12 · 三场景同款工作台（开箱版）

> 目标：新手把这一夹丢给**自己的 DSH**，读完、照着做，就能得到一台和「淋雨家的工作台」**长得一样、功能一样**的工作台：
> **三个场景**（自我复盘 / 本地电脑 / 设计杂活）+ **同款顶栏**（5 个网页端按钮、CPU·GPU·内存、场景刷新、插件/技能/工具/模型、余额、场景标签的「正在工作」光效）+ **同款名字与外观**。
> 全部内容**不含任何个人隐私**（没有本机用户名、没有客户名、没有会话 id、没有内网地址）。

本夹只放**能直接抄的配置 + 给 DSH 的提示词 + 自检清单**，不重复 10-源码 / 07-顶栏 里已有的原理。

---

## 一、先看清楚：这套东西分两半

| 两半 | 是什么 | 从哪来 |
|---|---|---|
| **外壳（Electron GUI）** | 窗口、顶栏、场景切换、面板网格、主题 | 你已经在用的工作台外壳（本仓库 10-源码 / 11-最小可运行壳 是参考实现） |
| **内容（本夹给的部分）** | 3 个场景配置、3 张身份卡、3 份记忆模板、顶栏各按钮的开关与样式 | **本夹** |

⚠ 本夹**不包含外壳程序本体**。你要有能跑起来的工作台外壳，才谈得上"同款"；只有 DSH 引擎的话，先看 11-最小可运行壳。

---

## 二、三步装完

### 第 1 步：把「给 DSH 的提示词」粘给新手自己的 DSH

打开 `01-给DSH的提示词.md`，**整段复制**，粘进它的对话里。
它会自动：探测本机 DSH 根目录 → 备份现有场景 → 创建 3 个场景 → 建 3 张身份卡 → 建 3 份场景记忆 → 报告改了什么。

### 第 2 步：核对它干得对不对

对着 `06-自检清单.md` 逐条打勾（8 条，都是能一条命令验的）。

### 第 3 步：重启工作台

场景是**启动时读**的，改完要重启工作台窗口（不是重启引擎）。重启后顶部会出现三个场景标签：
**自我复盘 / 本地电脑 / 设计杂活**，顶栏一整套按钮也都在。

## 四、同款清单（装完应该长这样）

### 顶栏左侧
- 品牌名：**淋雨家的工作台**
- 紧跟品牌后：**5 个网页端按钮**（豆包 / 通义 / DeepSeek / 智谱 / Kimi），点一下开一个内置窗口，再点收起

### 顶栏右侧
- **CPU 10% · GPU 9% · MEM 42%** 实时胶囊（点开看明细）
- `⟳` **场景刷新**（热更新，不打断对话）
- `🧩` 插件 · `✨` 技能 · `🛠` 工具 · `🤖` 模型
- **`¥ 余额`**（DeepSeek 平台余额，点开用量页）

### 场景栏
- 三个场景标签，图标可换
- **「正在工作」光效**：哪个场景的会话在干活，那个标签就呼吸发光（图标 + 标签一圈光环）

### 场景内部
| 场景 | 布局 | 面板 |
|---|---|---|
| **自我复盘** | 上 3+1、下 2+2 | 左预览（md/图片/视频/PDF/Office 内嵌）、右上文件树、左下网页版 AI、右下 AI 会话 |
| **本地电脑** | 上 3+1、下 2+2 | 磁盘分区卡（C/D/E/F 占比环）、磁盘大户排行、可清理体检、清理台账、AI 会话 |
| **设计杂活** | 上 3+1、下 1+3 | 预览、盘内文件浏览、项目管理（预留）、AI 会话 |

## 六、常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 重启后没出现场景标签 | 场景 json 放错目录 / 名字撞了 | 看自检清单第 2 条 |
| 场景点开是白屏 | 面板 `type` 这个外壳不认识 | 用 `03-身份卡` 里的面板清单，或先只留 `review-doc`/`file`/`harness` 三类 |
| AI 面板显示「会话不存在」 | `sessionId` 还是模板里的占位符 | 在工作台里先建同名会话，再把真实 id 填回 json |
| 顶栏没有网页按钮 | 外壳没有 `decorateWebAi` 这套注入 | 照 `05-顶栏/网页按钮.js` 补一个注入 |
| 光效不亮 | 少了 `.tab-working` 的 CSS 或没人给它加类 | 照 `05-顶栏/发光标签.css` + 让渲染器给"在干活"的标签加类 |
