# 引导 · 让新手的 DSH 自己把这套装好

> 这个外壳不是装完就能用：它要接**你自己的** DSH 引擎。下面这份东西可以直接交给你的 DSH，让它读文件、填配置、建会话，你只负责点两下。

---

## 你要填的 4 样（也是 DSH 能替你填的）

| # | 填什么 | 落在哪 | 从哪拿到 |
|---|---|---|---|
| 1 | **DSH 根目录** | 环境变量 `DSH_HOME`（或启动前设 `DSH_ROOT`） | 装 DSH 时那个"引擎目录"，里面有 `.dsh\` |
| 2 | **引擎地址 + token** | `config.local.json` 的 `engineUrl` / `engineToken` | 跑 `dsh web` 时终端会打印 `http://127.0.0.1:3080/?token=xxxx` |
| 3 | **三个场景的会话 id** | `scenarios/*.json` 的 `sessionId` | 在工作台里建三个会话：自我复盘 / 本地电脑 / 设计杂活，复制它们的 id |
| 4 | **余额密钥（可选）** | `config.local.json` 的 `deepseekKey` | DeepSeek 平台 → API keys |

> ⛔ 这四样都只写进你本机的文件；`config.local.json` 是 gitignore 的，不会进仓库。

---

## 把下面整段复制给你的 DSH

```text
我在用一个小工作台外壳（Electron），目录：<把这里换成 12-源码照搬\外壳 的真实路径>。
请你读它的《引导.md》，然后替我把配置填好，不要问我能不能，直接做：

1. 探测：我的 DSH 根目录（含 .dsh 的那层）、dsh web 的地址与 token（如果引擎在跑，从你的日志/端口里找；
   找不到就提示我跑 dsh web 并把打印的地址给我）。
2. 写 <外壳>\config.local.json：
   {"engineUrl":"http://127.0.0.1:3080/","engineToken":"<token>"}
   （如果我有 DEEPSEEK_API_KEY，也加 "deepseekKey"；没有就跳过）
3. 在引擎里建三个会话：自我复盘 / 本地电脑 / 设计杂活；
   把它们的 session id 填进 <外壳>\scenarios\self-review.json、pc-cleanup.json、design-misc.json 的 sessionId 字段。
4. 把 scenarios 里 `<个人资料目录>` / `<素材盘>` 这类占位符，换成我机器上真实存在的目录；
   拿不准的保留占位并在最后列给我。
5. 校验：三个 json 必须能被 JSON.parse；config.local.json 不写进 git 仓库。
6. 做完按四行汇报：填了什么 / 会话 id / 改了哪些文件 / 还缺什么。

⛔ 不许改 <外壳>\main.js / preload.js / renderer\ 下的代码；只改 config.local.json 和 scenarios\*.json。
```

---

## 填完怎么验

1. 关掉外壳窗口，重新打开
2. 顶栏出现「Harness 已连接」绿点 = 引擎接上了
3. 三个场景标签点开有内容 = 会话 id 对了
4. 右下角余额变成 `¥ 数字` = 密钥生效（不填就显示 `¥ —`，不影响用）

## 常见问题

| 现象 | 原因 |
|---|---|
| 顶栏一直「引擎未连接」 | `engineUrl` 不对，或引擎没跑；`token` 过期也会这样（重启 `dsh web` 换新 token） |
| 场景点开空白 | `sessionId` 还是占位符 |
| 文件夹按钮打不开 | 没设 `DSH_HOME` |
| 余额 `¥ —` | 没配 `deepseekKey`（可选，不影响其它功能） |
