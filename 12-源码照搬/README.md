# <机主>的工作台 · 公开模板

一套跑在本机的 **AI 工作台**：4 个场景、每个场景一个 AI 助手、记忆写在本地文件里。
不是聊天工具，是「把日常活分场景交给 AI，让记忆越用越厚」的一套工作方式。

> 只提供**工作台层**（界面 + 场景 + 记忆约定 + 工具）。引擎请自行安装 DSH（DSH 引擎）。

## 四个场景

| 场景 | 干什么 |
|---|---|
| **命令** | 总览：记忆网络（谁跟谁有关）+ AI |
| **B站** | 看视频 / 理解视频：网页 + AI |
| **自我复盘** | 预览 + 文件库 + AI：周报、复盘、资料 |
| **本地电脑** | 磁盘分区、大户排行、可清理体检、清理台账 |

## 快速开始

```powershell
# 1) 安装依赖（只需一次）
cd 外壳
npm install

# 2) 启动（会拉起你自己的 DSH 引擎，端口 3083）
cd ..
双击 启动.vbs

# 3) 给每个带 AI 的场景建会话
node 外壳\scripts\建会话.mjs "命令"
node 外壳\scripts\建会话.mjs "B站"
node 外壳\scripts\建会话.mjs "自我复盘"
node 外壳\scripts\建会话.mjs "本地电脑"
node 外壳\scripts\sessions.mjs --check
```

第一次用之前建议先跑：`node 工具\场景记忆.mjs list`，再用 `init --场景 <名字>` 生成每个场景的身份卡/画像。

## 记忆机制（这套工作台的核心）

```
引擎数据\.dsh\场景记忆\
  命令\场景私有记忆.md    ← 这个场景的记忆（唯一真源）
  命令\_文件索引.md       ← 它有哪些文件
  命令\归档\             ← 交接时旧版挪进这里
  _共享记忆\             ← 多个场景都要用的东西
```

- §〇 当前交接 **≤4 KB**：只写"下一轮要知道的"
- 交接才归档：`node 工具\场景记忆.mjs 交接 --场景 命令`
- 自检：`node 工具\场景记忆.mjs check --场景 命令`
- 跨场景留言：`node 工具\发消息.mjs --to B站 "帮我看下这个"`（纯文件，不发网络请求）

细节看 `说明\记忆约定.md`。

## 目录

```
外壳\            工作台界面（Electron）
引擎数据\.dsh\   这套工作台自己的数据（会话/记忆/技能/插件）
工具\            记忆、发消息、封装、发布前检查
说明\            记忆约定、使用说明
自我复盘\        自我复盘场景的默认资料目录
启动.vbs         启动器（端口 3083）
```

## 打包带走

```powershell
node 工具\封装.mjs --out <盘根>:\发布
```

会生成 `发布包-<机主>的工作台-<版本>-<日期>.zip` + `SHA256SUMS`，自动排除 node_modules / 引擎 / 本机数据。

## 二次开发

- 改面板/加场景：看 `外壳\scenarios\*.json` 和 `外壳\renderer\renderers.js`
- 加场景：复制一个 json、改 id/name、配 panels，再同步 `_场景身份索引.md`、跑 `建会话.mjs`
- 改完在 GUI 里点顶栏 ⟳ 刷新面板
