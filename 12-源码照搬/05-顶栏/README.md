## 一、5 个网页端按钮（网页版 AI）

### 站点表

| key | 名字 | 图标文件 | 强项 |
|---|---|---|---|
| `doubao` | 豆包 | `renderer\assets\webai\doubao.png` | 生图 / 生视频 / 日常问答 |
| `tongyi` | 通义千问 | `renderer\assets\webai\tongyi.png` | 生图（备选）/ 中文长文 |
| `deepseek` | DeepSeek | `renderer\assets\webai\deepseek.png` | 写代码 / 推理 |
| `chatglm` | 智谱清言 | `renderer\assets\webai\chatglm.png` | 写代码（主力）/ 结构化输出 |
| `kimi` | Kimi | `renderer\assets\webai\kimi.png` | 长文（实测输入框有时打不进） |

> ⚖ 这 5 张图标是**第三方站点标识**，商标归各家所有，这里只用于"点哪个站去哪个站"的辨识；
> 不是本项目/作者的资产，不要挪作他用。

### 行为约定（照这个做才和原版一致）

- **点一下开**：首次点击创建一个**独立的**内置窗口（webview），登录状态各窗口独立、互不影响；
- **再点收起**：不是销毁，是收起来（下次点回来**不用重新登录**）；
- **同时开**：5 个窗口互斥的关系**不存在**——可以同时开着（每个是一块独立 webview）；
- **图标用官网 favicon**（180×180 PNG），不要用 emoji 凑；图片挂了才退回单字。

> 📌 **这 5 张 PNG 已随本目录附带**（`05-顶栏/assets/webai/`，180×180）：复制到 `<外壳>\renderer\assets\webai\` 即可，文件名就是上表的 `key` + `.png`。

### DeepSeek 那一项要特别配（登录态共享）

- 站点表里 DeepSeek 的分区固定写 **`persist:embed-sr-site-bl`**，和自我复盘场景的内嵌面板（面板 id `sr-site-bl`）**是同一个分区**；
- ⇒ 在场景面板里登录过一次，顶栏按钮点开就是登录好的；反过来也一样；
- ⇒ `userAgent: 'chrome'` 必须写，否则 DeepSeek 会盖一层「使用环境异常」；
- ⚠ 分区名别改，改了两边同时掉登录。

### 放哪（桥的名字也在这里）

注入到 `#titlebar` 里、紧跟品牌名后面（`brand.nextSibling`），DOM 结构：

```html
<span id="webai-strip" class="webai-strip">
  <button class="webai-btn" data-key="doubao"  data-st="none" title="豆包（点一下开一个窗口，再点收起）"><img src="assets/webai/doubao.png" alt="豆包"></button>
  … 其余 4 个
</span>
```

⚠ **幂等**：场景刷新/热更新会重跑注入代码，`#webai-strip` 只许存在一份（先查再建）。

★ **桥名（照抄不会错）**：本机外壳暴露 `window.__kunWebAiToggle(key)` 和 `window.__kunWebAiOpen(key)`；
图标的样式（`.webai-strip` / `.webai-btn`）见 `顶栏.css`；
照抄成 `__appWebAiOpen` 这类别的名字 ⇒ 按钮会"退化成用系统浏览器打开"，看起来就是没反应。

## 二、负载胶囊（CPU / GPU / 内存）

- 位置：**顶栏最右侧**（在「最小化 ─ / 最大化 □ / 关闭 ✕」这一组的左边，不是 ⟳ 旁边），DOM：`<button id="tbs-load" class="tbs-pill tbs-load">`，内含三个 `.tbs-txt`：
  `CPU <b>10%</b>` · `GPU <b>9%</b>` · `MEM <b>42%</b>`
- 数据来源：外壳主进程读本机负载，**渲染层只拿数值**。本机版接口是 `window['kun'].sys.load()` 返回 `{cpu, gpu:{util,…}, mem:{usedPct}}`（见 `负载胶囊.js` 里按优先级探测的写法）；
- 刷新：**有窗口可见才轮询**（隐藏时不轮询，省电），间隔 3–5 秒；
- 着色：CPU ≥70% 黄、≥90% 红；**悬停**看数值明细（进程级占用要外壳另给 popover，本片段不做）。
  - 样式：`顶栏.css` 里的 `.tbs-pill.tbs-load` / `.tbs-txt` / `.tbs-k`（另有 `.webai-*` / `.rb-chip` / `.tb-more-*`）。

## 三、场景刷新 ⟳

- 行为：**重跑当前场景的渲染器 + 重读场景 json**，不重启引擎、不中断对话；
- 什么时候用：改了场景 json / 面板样式 / 面板脚本之后，点一下就能看到效果；
- 注意：`renderer\renderer.js`、`main.js`、`preload.js` 这种主进程/预加载脚本**改了必须重启工作台**，⟳ 不管用。

| 按钮 | 图标 | 点开看到 |
|---|---|---|
| 插件 | 🧩 | 已装插件列表（名字 / 版本 / 状态） |
| 技能 | ✨ | 技能目录（每个技能：名字 / 触发词 / 路径） |

原版还会在这四个右边放 `⚙ 设置`、`📁 文件夹`、`…` 菜单——新版精简掉了，**这 4 个按钮就是核心**。

这四个按钮**只负责打开你自己的本地目录/配置**，不内置任何人的清单：

| 按钮 | 打开什么 | 建议实现 |
|---|---|---|
| 🧩 插件 | 你的引擎插件目录 | `openPath(<引擎根>\\插件)` |
| ✨ 技能 | 你的技能目录 | `openPath(<引擎根>\\.dsh\\skills)` |
| 🛠 工具 | 你的工具目录 + 已注册工具列表 | `openPath(<引擎根>\\工具)` + 读你自己的注册表 |
| 🤖 模型 | 你的模型与提供方配置 | 读你的 `profiles` / credentials **只显示，不回显密钥** |

⛔ 不要把任何人的技能文件、记忆库、MCP 配置、工具清单、真实项目路径打包进来 —— 那些是各自的私有资产。

## 五、余额

- 位置：场景切换条右侧，DOM `<button id="balance-chip" class="balance-chip">¥ …</button>`
- 取值：**主进程**用配置里的 DeepSeek 密钥查平台余额，渲染层只显示数值（⛔ 密钥永不进前端）；
- 悬停：显示「充值 / 赠送 / 可用」明细；余额不足给 ⚠；点击打开用量页；
- 失败：显示 `¥ …` 并在 title 里写失败原因，**不许静默**。

## 六、「正在工作」光效

- 判定：该场景的会话**正在跑**（有未完成的步骤 / 有排队调用）⇒ 给这个场景的标签加 `tab-working` 类；
- 观感：**标签底部一条发光蓝条，1.2 秒呼吸一次**（光晕是静态 box-shadow，只有 opacity 在动）；图标同时做 .55↔1 的透明度呼吸；
- 浅色主题换更实的蓝；系统开了「减少动态效果」就常亮不呼吸。
- ⚠ 前提：`.tab` 要有 `position: relative`，底条才定位得上。

## 六·补：⋯ 菜单的目录路径从哪来

真实 preload 只暴露 `kun.app.openPath(p)`，**不提供**"外壳目录/数据目录"这样的路径。
所以 `⋯` 菜单里那两项只有在**外壳主动注入**路径时才显示：

```js
window.__SHELL_DIR       // 外壳可以在启动脚本里注入
window.__SHELL_DATA_DIR  // 同上
```

拿不到就**不显示这一项**（菜单只剩"版本信息"或"这个外壳没暴露可用的入口"）。
⛔ 不要拿 `app.dataDir` 这类不存在的属性硬猜路径。
