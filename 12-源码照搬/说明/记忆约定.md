# 记忆约定（1 页）

> 这套工作台的记忆是**文件**，不是聊天记录。每个场景一个文件夹，AI 开场先读它。

## 一、放在哪

```
引擎数据\.dsh\场景记忆\
  命令\场景私有记忆.md       ← 这个场景的记忆（唯一真源）
  命令\_文件索引.md          ← 这个场景有哪些文件
  命令\归档\               ← 交接时把旧版挪进来（只进不改）
  _共享记忆\               ← 多个场景都要用的东西
```

## 二、一份私有记忆的格式

- `## §〇 当前交接`：四小节（上次交接 / 当前项目 / 私有记忆变更 / 下一步·卡点），**≤4 KB**
- `## 核心职责`：≥3 条（负责什么 / 不碰什么 / 一句话）
- `## §一 ~ §五`：职责边界 / 现状接口 / 坑与决策（**只追加**）

## 三、四条铁律

1. **§〇 ≤4 KB**：只写"下一轮接手要知道的"，细节进 §五 或归档
2. **交接才归档**：`node 工具\场景记忆.mjs 交接 --场景 <名字>` 会把旧版挪进 `归档\`
3. **只追加**：§五 决策与坑只往下写，不改历史
4. **check 不过别换会话**：`node 工具\场景记忆.mjs check --场景 <名字>`

## 四、常用命令

```powershell
node 工具\场景记忆.mjs list                 # 看每个场景缺什么
node 工具\场景记忆.mjs init --场景 命令      # 生成身份卡/画像（首次）
node 工具\场景记忆.mjs stamp --场景 命令     # 重新生成身份卡/画像
node 工具\场景记忆.mjs 交接 --场景 命令      # 归档旧版 + 补 §〇
node 工具\场景记忆.mjs check --场景 命令     # 自检
```

## 五、跨场景

`node 工具\发消息.mjs --to B站 "帮我看下这个"` —— 纯文件，不发网络请求。对方下一轮读自己的 §〇-通知 就能看到。
