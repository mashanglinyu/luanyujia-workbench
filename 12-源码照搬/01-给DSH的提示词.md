# 01 · 给 DSH 的提示词（整段复制，粘进新手自己的 DSH）

> ℹ 这是「**体验我的工作台**」的安装提示词：装完是**我这台的样子**，供你体验/抄结构。
> 建议**自己搭**（见 04-工作台搭建）或**基于它改**；记忆和场景内容只能你自己长出来。

> 用法：把下面整段（从 `===` 之间）复制给你的 DSH。它读完会自己探测路径、自己建文件、最后给你一份"改了什么"的清单。
> ⚠ 先确认：你已经有**能跑起来的工作台外壳**（有 `scenarios\` 目录），否则先看 `11-最小可运行壳`。

---

```
我要你把这套场景内容 + 顶栏片段搬到我机器上：三个场景（自我复盘 / 本地电脑 / 设计杂活）+ 顶栏片段 + 外观（工作台名字先按资料 README 里那个名字，装完我自己改）。
资料在附件文件夹 `12-源码照搬\`（如果我没给路径，先问我，别猜）。

【第零步·先跑壳】
本夹自带最小外壳：进 `12-源码照搬\外壳` 跑 `npm install` 再 `npm start`（没装 Node 先装 Node 18+）。
能跑出三个场景标签 + 顶栏就算过；跑不起来先解决这个，别急着往下放配置。

【第一步·只探测，不改】
1. 找到我的 DSH 根目录（引擎目录）和工作台外壳目录（外壳目录）。
2. 确认这四个位置存在，打印绝对路径给我看：
   - <外壳目录>\scenarios\          （场景 json + 身份卡都放这里）
   - <引擎>\场景项目信息\        （每个场景一份长期记忆）
   - <外壳目录>\renderer\           （顶栏/光效在这层的前端里）
   - <引擎>\.dsh\skills\             （技能目录）
3. 列出 scenarios\ 里已有的场景 json 名字，标出哪些和我这三个重名。

【第二步·备份】
把 scenarios\ 整个目录复制一份到 `scenarios.bak-<今天日期>`，并告诉我备份路径。

【第三步·放三个场景】
从资料 `02-场景\` 复制这三个文件到 <外壳目录>\scenarios\：
  self-review.json / pc-cleanup.json / design-misc.json
规则：
- 文件里的 `"sessionId": "__待填__"` 先原样保留，第 5 步再填。
- 如果撞名，改名（如 `self-review-2`）并把 json 里的 id/name 一起改，别覆盖我原来的。
- 场景布局面板类型如果我的外壳不认识（review-doc / review-files / view / file / harness / reserved / pc-* 这些），
  告诉我哪几个不认识，然后**只保留我外壳支持的**，其余先注释掉（在 json 里加 "_note" 字段记着，不要删文件）。

【第四步·身份卡和记忆】
1. 从资料 `03-身份卡\` 复制三张卡到 <外壳目录>\scenarios\：
   self-review-context.md / pc-cleanup-context.md / design-misc-context.md
2. 从资料 `04-记忆模板\` 复制三份记忆到 <引擎>\场景项目信息\ 下，按场景名建文件夹：
   场景项目信息\自我复盘\项目信息.md
   场景项目信息\本地电脑\项目信息.md
   场景项目信息\设计杂活\项目信息.md
   卡里的 `<...>` 占位符，按我机器真实路径替换；拿不准的保留占位符并在报告里列出来。

【第五步·建会话并回填 id】
这三个场景各需要一个 AI 会话（标题必须和场景名一字不差：自我复盘 / 本地电脑 / 设计杂活）。
- 能用工作台界面建的，就引导我在界面上点「新建会话」并命名；
- 你能用命令建的（比如工作台的换会话脚本），就直接建，建完把会话 id 告诉我。
拿到三个 id 后，回填到对应场景 json 的 `sessionId` 字段（还有 `pinTarget`/`sessionTitle` 按卡里的写法对齐），并备份一次 json。

【第六步·顶栏片段（可选，需要手工接）】
读资料 `05-顶栏\README.md` 的清单，对照我的外壳现状告诉我：哪几项已经有、哪几项缺。
⚠ 注意：本夹**不含外壳本体**，也不含任何人的技能/记忆/MCP 配置；缺的部分要么我外壳本来就有，要么按片段手工接。
缺的按 `05-顶栏\` 里的样式/脚本补，改完必须告诉我「改的是哪个文件、要不要重启」。
⚠ 改外壳前端前先备份；⛔ 不要动引擎二进制、不要动 启动器\ 里的 exe。

【第七步·验收 + 报告】
逐条跑 `06-自检清单.md` 里的检查，把结果贴给我。最后按六行报告：
1. 场景文件：放了哪 3 个、路径
2. 身份卡：放了哪 3 张、路径
3. 记忆：建了哪 3 份、路径
4. 会话：3 个标题 + 3 个 session id
5. 顶栏：原来有什么 / 补了什么 / 要不要重启
6. 卡点：拿不准或没做成的，逐条列出来（⛔ 不许静默跳过）

【铁律】
- ⛔ 不删我原有的任何场景、卡、记忆；只新增或备份后修改。
- ⛔ 不装来源不明的 exe/ps1；只复制文本文件。
- ⛔ 路径拿不准就问我，不许猜着写。
- ⛔ 不要把我机器上的任何路径、账号、密钥写进这三个场景的 json/卡里（本资料本身就是脱敏的，照抄即可）。
```

## 附：给"没有工作台外壳"的人

如果你只有 DSH 引擎、没有外壳，先做这两件事，再回来贴上面那段：

1. 看 `11-最小可运行壳\`，把单文件 demo 跑起来（双击即可），确认你要的是这个形态；
2. 或者装一个 Electron 工作台外壳（本仓库 `10-源码\` 里有面板与顶栏的参考实现）。

没有外壳也能得到"三个场景的对话身份 + 记忆"，只是没有图形化的面板布局——那种情况下，跳过着第五步里的界面操作，只建会话 + 回填 id 即可。
