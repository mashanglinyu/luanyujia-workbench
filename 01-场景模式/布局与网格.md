# 布局与网格

> 面板摆放 = **网格上的坐标**：`col` / `row` 是起点，`w` / `h` 是跨几格。
> 只要记住一句话：**列数是可配的，行是等分的。**

---

## 1. 网格长什么样

- 默认 **4 列**，列宽等分；行高也等分（`grid-auto-rows: minmax(0, 1fr)`）；
- 面板之间是固定间隙，面板内容自己滚动，整页不滚；
- 每个面板就是一个网格项：`grid-column: <col> / span <w>`、`grid-row: <row> / span <h>`。

```
         第1列        第2列        第3列        第4列
第1行  ┌───────────┬───────────┬───────────┬──────────┐
       │  A：col1 row1 w3 h2                 │ B：col4 row1 w1 h2 │
第2行  ├───────────┼───────────┼───────────┼──────────┤
       │                                     │          │
第3行  ├───────────┴───────────┼───────────┴──────────┤
       │ C：col1 row3 w1 h1    │  D：col2 row3 w3 h2  │
第4行  ├───────────────────────┤                      │
       │ E：col1 row4 w1 h1    │                      │
       └───────────────────────┴──────────────────────┘
```

（上图的 A/B/C/D/E 就是"上 3 下 1 + 左下再切两格"的常用版式。）

---

## 2. 四个数字怎么算

| 字段 | 含义 | 默认 |
|---|---|---|
| `col` | 起始列，**从 1 开始** | 自动 |
| `row` | 起始行，**从 1 开始** | 自动 |
| `w` | 跨几列 | `2` |
| `h` | 跨几行 | `2` |

- **只写 `w`/`h`、不写 `col`/`row`** → 该面板进入自动流；
- **整份 json 一个坐标都不写** → 全场景自动排版：渲染完自动补洞、拉伸填满（避免半路留大空洞，把下面所有面板一起压扁）；
- **写了起点** → 就落在这一格，向右跨 `w`、向下跨 `h`。

> 坐标是**起点 + 跨度**，不是终点。`col: 4, w: 1` 才是"最后一列"；写 `col: 4, w: 2` 会伸到第 5 列去（见下面越界）。

---

## 3. `cols`：什么时候需要改列数

列数是**比例的最小单位**。4 列能表达 1:3、2:2、3:1，**表达不了 2:3**。
要"五分之三 / 五分之二"这种比例，就把 `cols` 调大：

```json
{
  "cols": 20,
  "panels": [
    { "id": "a", "title": "主区", "type": "view", "col": 1,  "row": 1, "w": 12, "h": 2 },
    { "id": "b", "title": "侧栏", "type": "file", "col": 13, "row": 1, "w": 8,  "h": 2 }
  ]
}
```

（12/20 = 3/5，8/20 = 2/5；原来的 3:1 也可以用 15+5 原样保持。）

⚠️ **改 `cols` 要回头检查所有面板坐标**：面板伸到声明列数之外时，网格会长出"隐式列"（按内容宽排，不是等分）⇒ 比例整个乱掉。
宿主发现越界时会**按实际需要的列数渲染并打印一条告警**（控制台），不会画歪，但要你去把坐标或 `cols` 改齐。

## 4. 常见版式

| 版式 | 坐标 |
|---|---|
| **上 3 下 1**（大预览 + 右侧栏） | A `col1 row1 w3 h2` ｜ B `col4 row1 w1 h2` |
| **左 1 右 3** | A `col1 row1 w1 h2` ｜ B `col2 row1 w3 h2` |
| **左右各半** | A `col1 row1 w2 h2` ｜ B `col3 row1 w2 h2` |
| **2 × 2** | A `col1 row1 w2 h1`、B `col3 row1 w2 h1`、C `col1 row2 w2 h1`、D `col3 row2 w2 h1` |
| **上下通栏** | A `col1 row1 w4 h1` ｜ B `col1 row2 w4 h1` |
| **主区 + 侧栏 + 底部工具条** | 主区 `col1 row1 w3 h2`｜侧栏 `col4 row1 w1 h2`｜工具条 `col1 row3 w4 h1` |

> 一条实践：**把最大的那块留给 AI 面板**（通常是 `w3 h2`）—— 它是停留时间最长的地方。

---

## 5. 面板"展开到最高"

标题栏的 **▲** 把该面板临时撑到**整个网格的高度**：盖住其它面板，而其它面板位置**完全不动**
（实现上是在原格插一个占位格把版面钉住，再把面板改成覆盖层，动画只改高度）。

- 再点一次收起，`ESC` 也能收；
- 可以同时展开多个；
- AI 面板自带这个按钮，其它类型在 json 里写 `"expand": true`。
