## 2. 会话卫生（预防比抢救便宜）

- **一个话题一个会话**；长任务**分段落地**：阶段性结论写进文件（场景 `项目信息.md`），下次读回来。**文件是无限的，会话上下文不是**。

  硬上限：同一件事 **≤3 条消息**（派单+回执+收尾）；⛔ 纯确认语（收到/好的/谢谢）不许发；收到知悉一个字都不许回。核实：`待回执.mjs --me <面板>` 或 `读会话尾巴.mjs --to <面板>`。
  - ★★ **长任务做完必须回执结束（2026-10-19 宿主亲口：「以后如果有长任务要确保工作完成后回执结束，每个 ai 都要有这个意识」）**：任何**多步/耗时/跨会话**的活，**干完或卡住都要主动发一条回执**给发起方（格式 `【不需要回执·知悉】结论 + 证据 + 落盘路径`）；**⛔ 不许只在自家窗口说一句"我做完了"就当交付**（发起方收不到 = 没闭环）。同理，收到别人的长任务派单，**开工时也要回一句"收到，在做"**（避免对方空等）。
  - 判据：**"活干完了但对方还不知道" = 没干完**。
- ★★ **发完就结束（2026-10-18 宿主亲口）**：调 `通知场景 --wake` 发完 ⇒ **本 turn 直接结束**；对方回执会作为消息进本会话 inbox，**下一轮自然看到**。
  ⛔ 不要在 turn 里 sleep 等回执、也不要靠 `读会话尾巴` 找（对方回执发进我 inbox、不在它自己日志里 ⇒ 翻日志会误判）。`读会话尾巴` 只当兜底。
- ⛔⛔ **禁止无限对话**（《跨场景协作》§二 **规矩 10**）：**一次派单 = 一条回执 = 一条收尾知悉 = 结束**（≤200 字/≤10 行）；首行标记 + 末行 `【结束】`；收到知悉**一个字都不许回**；同一任务 ≤3 条消息；帮手之间不互发；见 `Insufficient Balance`/402 立即停派单（规范 §6.6）。
- ★ **出方案用免费 AI `顾问团`**（默认 2 站、不超 3、机密硬拦）：`顾问团.mjs "<问题.md>" --n 3 --round2 --from <场景>`，只读它收成的 `_汇总.md`；建议自己核过再落文件（规范 §6.6 / 技能 `webai-offload` §2）。
- ★★ **会话档案（核心资产 · 根目录）**：`<DSH根>\会话档案\`（`_索引.md` + `核心\` + `概览\`）。**每次换会话后跑** `node <DSH根>\工具\会话档案.mjs --root` ⇒ 旧 sessionId 进历史、新 sessionId 成当前、索引自动刷新（这就是"自动接续"）。分级：**自我复盘 / DSH改造 留关键信息**（§〇 原文 + §五 最近 5 条），其它场景只记大概。⛔ 别把聊天正文抄进档案；全文走 GUI 导出或 `读会话尾巴.mjs`。
- ★★ **没人认领的任务归 `dg-dsh` 分诊**：抓手 `任务分诊.mjs`；判"该谁" → 派单 / 自己做并在**台账**落一行 / 拿不准问用户（口径《跨场景协作》§二 规矩 7）。

## 4. 工作台「场景面板」的会话：开场先认领身份（30 秒，省几小时返工）

1. 跑 `$env:DSH_SESSION_ID` 拿本次会话 id。
2. 在 `<DSH根>\外壳\scenarios\_场景身份索引.md` 对号（§二/§五）⇒ 场景 / 定位卡 / 主技能 / 场景项目信息。
3. 读那张**定位卡**（身份职责、资产地图、触发词、铁律、上次进度）+ 主技能。
4. 读该场景**项目信息**的 `§〇 当前交接 + §一 + §二`（`引擎\场景项目信息\<场景>\项目信息.md`）；卡与项目信息**一次读够，别每轮重读**。
- 卡与技能/项目信息冲突 ⇒ **以技能与项目信息为准**；**分层**：`资产归属/路径` 看卡（卡是资产地图的权威）、`身份/流程/判据` 看技能 + 项目信息（2026-10-17 裁决）。不在表里 = 普通会话，忽略本节。
- 「DSH·GUI改造」**一个场景两条会话**：左 `dg-dsh` 只写 `引擎\`、右 `dg-gui` 只写 `外壳\`，共用定位卡；**重启引擎 / 关 GUI 只能由用户做**。
- **零散会话**（不在表里）：要落盘/交接就写 `引擎\场景项目信息\其他会话临时项目信息交接文档\<会话名>-<YYYYMMDD-HHMM>.md`；别给它建场景/定位卡。换会话别手工做（只改名不算归档、空会话不进侧边栏）。
- **干完活要写回**：新决策/新坑 → 项目信息 `§五`（只追加）；进度/下一步/卡点 → 覆盖 `§〇`；新坑/新路径 → 场景技能。**换会话前必须先写好 `§〇`**。
- ★★ **10 条会话是"同事"**：职能 / 地盘 / 重叠时听谁的 / 怎么互相找 ⇒ `外壳\scenarios\_跨场景协作.md`；要别人配合就往它 `§〇` 写一行请求，**别替它删东西**。

## 5. 用户说「换会话」= 你替他执行，别只教他敲命令

触发词：**「换会话 / 归档并新建 / 换个新会话 / 换新会话 / 这条太长了换掉」**，或点名面板（「给 mk-chat 换会话」）。听到就动手，一条命令都不用他敲：

1. `node "<DSH根>\外壳\scripts\换会话.mjs" <面板id>` 先看一眼（只打印交接文件路径与多旧，不改任何东西）。
2. **把这次会话的「进度 / 下一步 / 卡点」覆盖写进该场景 `§〇`** —— 这一步就是交接，别省。
3. `node "<DSH根>\外壳\scripts\换会话.mjs" <面板id> --go` ⇒ 新建同名会话 → 旧会话改名「已归档 · …」→ 回写场景 json → 自检。
4. 告诉用户：在那个面板点一次 ⟳ 就接上（新会话开场已收到"读 §〇"的指令）。
- **换自己这条**：第 2 步后加一句提醒（"这条对话就此结束，记忆只在 `§〇` 里"），他确认/催了再 `--go`；跑完你这条就**被归档**了 ⇒ 把"本轮做了什么、`§〇` 记了什么"放进**最后一句**。
- 用户没写 `§〇` 也没关系：**你替他写**（写完即"新鲜"，2 小时闸门自然放行）；真不想写才 `--force`。
- ⚠/⛔ **不是换会话的理由**（见 §1）；只有用户自己说「换会话」、或压缩之后仍然 413（真死锁）才换。
- 细则与底层命令（`sessions.mjs --rotate --stray`、RPC 配方、§〇 ≤4 KB 交接协议）：技能 `context-overflow` §6 + 规范 §6.5。
