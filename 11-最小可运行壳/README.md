# 11 · 最小可运行壳 —— 一个文件，双击就能跑

> 前面十个板块讲的是"怎么做"。这一节是**能立刻点开看的东西**。
>
> **怎么跑**：双击 [`index.html`](index.html) 就行 —— 单文件、零依赖、不用装任何东西。
> （想用本地服务器：`npx serve .` 然后开 `/11-最小可运行壳/`。）

---

## 5 分钟看这 4 下

| # | 动作 | 你会看到 |
|---|---|---|
| 1 | **点顶上的标签**（📁 / 🤖 / ⬚） | 整个界面按"场景"换掉 —— 这就是"一个窗口 = 一块场景" |
| 2 | **按住标签左右拖** | 标签换位；⚠ 拖完**不会误切场景**（这是真实事故换来的判据） |
| 3 | **在左边文件列表点一个文件** | 右边「预览」面板打开它 —— 两个面板互指，靠配置里的 `filesPanel` |
| 4 | **在 🤖 面板点「换会话」** | 会话 id 与标题一起变，并弹出一条提示：**三处要同步**（场景 json / 索引表 / §〇 交接） |

窗口底部状态栏会实时显示：引擎状态 · 当前场景 · 当前会话 · 面板数。

## 它**不是**什么（先说清，省得你失望）

| 不是 | 说明 |
|---|---|
| ❌ 不是真实工作台 | 数据全是假的（假文件树、假会话、假引擎） |
| ❌ 不接任何 AI | 🤖 面板里那两句是**写死的**，没有网络请求 |
| ❌ 不持久化 | 刷新就回到初始顺序与初始会话 |
| ❌ 没有 Electron | 纯 HTML/JS，所以才能"双击就跑" |

> 它的定位：**把"机制长什么样"压缩到 600 行内**，让你先跑起来，再决定要不要读那 7,600 行真代码（[`../10-源码/`](../10-源码/)）。

## 想把它变成真的（三步）

```
① 换掉 app.file 的两个方法
   list(dir)  → fs.readdirSync / Electron IPC
   read(path) → 只读前 8KB（大文件别整篇载入）

② 换掉 app.session
   current / rotate() → 你真实的会话系统（引擎里建会话、拿 id、归档旧会话）

③ 把 SCENES 换成"读目录里的场景 json"
   （真实工作台就是这么做的：scenarios/*.json → 标签栏 + 网格 → 面板）
```

做完这三步，它就是一个**能用的壳**了；剩下的是"要不要 Electron"（取决于你要不要真窗口、托盘、文件系统权限）。

## 已知的简化（别当成 bug）

1. **拖拽只做了"换位"**，没做真实版的 FLIP 让位动画（[07 的真实现](../07-顶栏与菜单栏/2-标签交互（热更新侧）.js) 里有）；
2. **`view` 只渲染文本**，没做图片/PDF/网页预览；
3. **换会话是模拟的**：它不会真的建会话，只演示"三处同步"这个动作；
4. **顺序不持久化**：真实版由主进程写文件（"单一权威"那条）。
